# Windows system DLLs that a clean Windows 10 and Windows 11 both have (plan Task 17 Step 3; builder's call).
# Read by `cargo xtask pe-check` (xtask/src/pe.rs) through include_str!.
# One name per line, without the .dll ending; letter case is ignored; a trailing * means "starts with".
# `api-ms-win-*` is special: it accepts the API-set names only (api-ms-win-<contract>-l<n>-<n>-<n>, for
# example api-ms-win-core-synch-l1-2-0), never a name with a path character, a dot or an empty part.
# The list is applied to the delay-load imports too (a DLL loaded on first use is an import all the same).
# No lib*.dll here: a mingw runtime DLL (libwinpthread, libgcc_s, libstdc++) is never a system DLL.
