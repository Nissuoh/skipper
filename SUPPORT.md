# Getting help

**Status as of 0.1.0-test.6 (2026-11-09):** Skipper is not released and nothing is published, so there is nothing to install and nothing to troubleshoot. Help today is about the documents; the [README](README.md) holds the full status.

## Where questions go

- **A question about the design or the documents.** Read the [README](README.md) and the [glossary](docs/glossary.md) first, and the design document once it is here (it follows with the code; documents first). If the answer is not there, open an issue with the "Design feedback" form and choose "A question".
- **A question, an idea or a chat.** Join the Skipper Discord server (<https://discord.gg/9kggrpKCvQ>). The help forum is for questions and the ideas forum is for ideas. It is a public community chat and replies are best effort. For a question about the design or the documents that should leave a record, use the GitHub route above.
- **A bug in Skipper.** Once a build is published, use the "Bug report" form on GitHub; the bugs forum on Discord points to it. Before that, there is nothing to report.
- **News.** Follow the project on X (<https://x.com/Skipper_OS>). It is for news, not for support.
- **A security problem.** Never in public, except the contentless contact request that [SECURITY.md](SECURITY.md) describes. Follow [SECURITY.md](SECURITY.md).
- **A conduct problem.** Never in public. Follow the [code of conduct](CODE_OF_CONDUCT.md).
- **Claude Code itself, your Claude account, your subscription, usage limits or sign-in.** Skipper cannot help with these and never reads your sign-in data. Use Anthropic's channels: the [Claude Code documentation](https://code.claude.com/docs/en/overview), `/feedback` inside Claude Code for a bug in Claude Code, and Anthropic's [Help Center](https://support.claude.com) for account and billing questions. A security problem in Claude Code goes to Anthropic first, as [SECURITY.md](SECURITY.md) describes under "Problems in Claude Code".

## Discussions

GitHub Discussions stay switched off (owner decision, 2026-10-21). Questions that need a record go through the "Design feedback" form, and open conversation goes to the Discord server above. If the owner switches Discussions on later, this page and the issue forms change first.

## What to expect

Skipper has one maintainer (see [GOVERNANCE.md](GOVERNANCE.md)). Replies are best effort, there is no fixed deadline, and there is no private support or e-mail. The Discord server is a public community chat, not a support line. Never post credentials, tokens, session transcripts or personal data, your own included, on GitHub or on Discord. No one from the project asks for your Claude password, a sign-in code or a token, on Discord, on X or anywhere else.
